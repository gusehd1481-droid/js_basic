## 변수 작성시 주의 사항
* 변수의 이름은 문자(a~z, A~Z), 숫자(0~9), 달러($), 밑줄(_)이 포함됩니다.
* 변수의 이름은 숫자로 시작할 수 없습니다.
* 변수의 이름은 대시(-)나 마침표(.) 기호를 사용할 수 없습니다.
* 키워드나 예약어는 사용할 수 없습니다.
    키워드, 예약어 종류 -> `delete,this, false,true, if, default, var, new, class` 등
* 모든 변수는 대/소문자를 구별합니다. score와 Score는 다른 변수입니다 !
* 변수가 저장할 정보의 종류를 표현하는 의미있는 단어를 사용해야 합니다 !

## 데이터타입 구분 함수 `typeof()`
* CSS의 배경색상으로 영역구분하는 것처럼 데이터타입 구분목적 사용
1. 특정 데이터타입을 담아둔 변수를 생성
    * `let num = 1;`
    * `let str = 1;`
2. 해당 변수의 데이터타입을 구분하기 위해 typeof 함수확인
    * `console.log(typeof(num));` //Number(숫자)
    * `console.log(typeof(str));` //String(문자)

## 복합대입 연산자
* 코드에 간결함을 위해 사용한다. 사칙연산 모두 복합 대입연산자 적용이 가능하다.
* `예시` a += b    `예시 뜻` a = a + b  `예시 풀이` 기존 a값에 b를 더하여 a에 대입한다.
* `예시` a -= b    `예시 뜻` a = a - b  `예시 풀이` 기존 a값에 b를 빼서 a에 대입한다.
* `예시` a *= b    `예시 뜻` a = a * b  `예시 풀이` 기존 a값에 b를 곱해서 a에 대입한다.
* `예시` a /= b    `예시 뜻` a = a / b  `예시 풀이` 기존 a값에 b를 나눠서 a에 대입한다.
* `예시` a %= b    `예시 뜻` a = a % b  `예시 풀이` 기존 a값에 b를 나눈 나머지 값을 a에 대입한다.
* 계산할 수 없는 경우 NaN, `NaN` : Not a number = 오류
* `더하기`를 제외한 `빼기`, `곱하기`, `나누기` 연산자는 피연산자의 형태가 문자라하더라도 `''`제거시 숫자로 인식될 수 있는 경우 숫자로 인식 한다.
